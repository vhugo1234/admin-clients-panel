# Features Documentation

## Complete Feature List

### 1. Global Search
- Search across multiple fields simultaneously
- Supported fields: name, schema, responsible name, email, domain
- Real-time filtering
- Case-insensitive matching

### 2. Advanced Filtering
- **Status Filter**: active, inactive, pending, suspended
- **Plan Filter**: free, premium, enterprise
- Filters work in combination with search
- Clear visual indicators for applied filters

### 3. Summary Cards
- **Total Clients**: Count of all client records
- **Total Users**: Sum of all users across all clients
- **Total Assets**: Sum of all assets across all clients
- Auto-updates when filters are applied

### 4. Dark/Light Mode Toggle
- Smooth transition between themes
- Persistent across sessions (ready for localStorage integration)
- Affects entire UI including modals and tables

### 5. CSV Export
- Exports filtered results
- Includes all relevant client data
- Properly formatted dates
- UTF-8 encoding with BOM for Excel compatibility
- Automatic filename with current date

### 6. Client Actions

#### Edit Client
- Full form with all client fields
- Logo upload with preview
- Auto-generates schema name from company name
- Validates required fields
- Updates existing client data via API

#### Delete Client
- Confirmation dialog before deletion
- Prevents accidental deletions
- Removes client from database via API
- Updates UI immediately after deletion

#### View Logs
- Displays client activity logs
- Mock data included for demonstration
- Color-coded log levels (INFO, WARN, ERROR)
- Timestamps for each log entry
- Scrollable log viewer

#### Zoom Logo
- Full-screen logo viewer
- High-quality image display
- Close button for easy dismissal
- Handles missing logos gracefully

#### Copy Admin Password
- One-click copy to clipboard
- Visual confirmation when copied
- Displayed when creating new client
- Secure handling of temporary passwords

### 7. Create/Edit Modal

#### Client Information
- Company name
- Schema identifier (auto-generated or manual)
- Domain URL
- Plan type selection
- Status selection
- Expiration date

#### Logo Upload
- File selection with preview
- Supports common image formats (PNG, JPG)
- Clear/remove logo option
- Visual indicator for new uploads
- Server upload via API

#### Responsible Contact
- Name
- Email (required)
- Phone number

#### Admin User Creation
- Admin name
- Admin email
- Admin password
- Tooltips for guidance
- Password auto-generated by server on creation

### 8. Animated Loader
- Displays during data fetching
- Material-UI CircularProgress component
- Centered in content area
- Smooth fade-in/out transitions

### 9. Table Features

#### Pagination
- Configurable rows per page (5, 10, 25)
- Page navigation controls
- Shows current range (e.g., "1-10 of 50")
- Portuguese labels

#### Sorting
- Infrastructure ready for column sorting
- Ascending/descending order
- Maintains sort across pagination
- Currently sorts by ID (expandable to all columns)

#### Columns
1. **Logo**: Thumbnail with zoom capability
2. **Name/Schema**: Company name with schema identifier
3. **Domain**: Clickable link to client domain
4. **Responsible**: Name, email, phone
5. **Total Users**: Badge with count
6. **Total Assets**: Badge with count
7. **Plan/Status**: Color-coded chips
8. **Expiration**: Formatted date
9. **Last Access**: Formatted date
10. **Actions**: Edit, Delete, Logs buttons

### 12. API Integration

#### Endpoints Used
```
GET    /api/admin/tenants           - List all tenants
POST   /api/admin/tenants           - Create new tenant
PUT    /api/admin/tenants/:id       - Update tenant
DELETE /api/admin/tenants/:id       - Delete tenant
POST   /api/admin/upload/logo       - Upload tenant logo
```

#### Request/Response Handling
- Automatic token injection via interceptors
- Error handling with user-friendly messages
- Loading states during API calls
- Optimistic UI updates where applicable

#### Authentication
- Token-based authentication ready
- AuthContext integration
- Automatic redirect on 401 errors
- Token stored in localStorage
